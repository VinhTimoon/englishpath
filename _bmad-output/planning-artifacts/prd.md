# PRD Summary

## Objective

Establish project governance that lets BMAD plan work and Codex implement work safely, one story at a time.

## Requirements

- Every change must map to a story.
- Every story must declare allowed and forbidden paths.
- Codex must use the skill router for context selection.
- Verification commands must be run or reported missing.
- App source code must remain untouched in governance-only stories.

## Success Criteria

- Governance docs exist and are internally consistent.
- Planning and implementation artifact folders are present.
- Story folders are present.
- Foundation stories can proceed without loading unrelated project context.
