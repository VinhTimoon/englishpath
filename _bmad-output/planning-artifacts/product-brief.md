# Product Brief

## Product

EnglishPath is a free-first English learning platform built for Vietnamese learners.

## Problem

The project needs a clear governance baseline so automated implementation follows the same story, routing, and quality rules every time.

## Users

- Learners using the platform
- Product and delivery stakeholders defining scope
- Engineers and agents implementing stories

## Outcome

- Story-led implementation
- Minimal context loading
- Predictable skill routing
- Clear verification before completion
